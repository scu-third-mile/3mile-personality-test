# 東吳第3哩｜環島角色測驗 1011_BE_v5

目前網站與統計傳送版本：`1011_BE_v5`。

## 本版調整
- 認證日報名撤下連結，改顯示「尚未開放」。
- 環島說明會報名使用已確認的 Google 表單網址。
- 結果圖片說明只保留兩段，段落內依實際文字寬度自然換行，不指定換行位置；保留完整原文。
- 四種角色比例區塊的列距為 78px，避免角色圖片互相重疊。
- 網頁引用 CSS 與 JavaScript 時加入版本號，避免更新後繼續沿用舊快取。
- 保留現有角色圖片、題目、計分、結果網頁及後端接收網址。

## 上傳方法
1. 解壓縮，將內部檔案與完整 assets 資料夾上傳 GitHub 儲存庫根目錄，覆蓋同名檔案。不要直接上傳 ZIP 或外層資料夾。
2. 特別確認 index.html、script.js、backend.js、README.md 都有更新。
3. 等 GitHub Pages 部署完成，關閉舊的測驗分頁，再重新開啟網站並重新作答、保存圖片。既有相簿圖片不會被更新。

## 後端版本驗證
Apps Script 的版本規則應為：
```js
const versionPattern = /^(?:1010|1011)_BE_v[1-9]\d*$/;
```
若已套用並部署此規則，本版不需重新部署後端。完成測驗後，請在 Google Sheets 確認新增資料的版本欄為 1011_BE_v5。
backend-config.js 沿用原有 Web App /exec 網址。

## 背景傳送規則
- 每次開始或再測一次建立新的隨機 UUID，完成 Q8 產生結果時送出一次。
- 結果頁與圖片頁來回切換不會重複提交。
- 使用 no-cors 背景傳送，不等待後端、沒有自動重試；瀏覽器無法確認實際儲存成功，請以 Google Sheets 新增紀錄為準。
- 傳送失敗不影響測驗結果與保存圖片。
- 未設定接收網址，或瀏覽器不支援 crypto.randomUUID() 時不傳送。
- 此公開接收設計不防惡意假提交；前端不可放密碼或私密金鑰。
