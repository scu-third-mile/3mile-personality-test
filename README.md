# 東吳第3哩｜環島角色測驗 1009_v2

以 1009_v1 為基礎修改，保留原本題目、計分、結果判定、連結與宇宙虹彩玻璃主視覺。

## 本版更新
1. 首頁縮短
   - Rover 合輯保留，但縮小高度。
   - 縮短首頁上下留白、文字間距與卡片間距。
   - 最上方活動標籤縮小並強制單行，降低窄螢幕斷行機率。
   - 目標是讓「開始測驗」更容易在手機首屏直接看到。

2. 結果頁代表話與說明文字
   - 降低代表話字級。
   - 避免中文短句出現尷尬的單字斷行。
   - 紫色結果卡保留。
   - 說明段落行距稍微整理，提升閱讀性。

3. Rover 位置
   - 移除結果卡右上角 Rover。
   - 改使用使用者提供的透明 `rover.png`。
   - 放到「來自第3哩團隊的小提醒」右上角並縮小。

4. 結果頁玻璃卡外框
   - 移除傾向卡、小提醒、活動資訊與收尾卡片的灰色外框。
   - 改由玻璃背景與淡陰影區分層次。

5. 四種角色圖示 Rover 化
   - 沿途探索家：相機 Rover。
   - 熱血挑戰者：騎單車 Rover。
   - 穩定節奏型：地圖 Rover。
   - 夥伴黏著劑：兩隻 Rover 合成的夥伴版。
   - 主結果與「四種環島傾向」列表皆使用 Rover 圖示。
   - 雙重角色結果會並排顯示兩個 Rover。
